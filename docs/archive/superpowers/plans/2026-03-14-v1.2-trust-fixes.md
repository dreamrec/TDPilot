# TDPilot v1.2 Trust Fixes Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix naming drift, transport inconsistency, and dependency pinning so TDPilot v1.2.0 passes its own doctor on clean checkout.

**Architecture:** Add `TOX_FILENAME` and `normalize_transport()` to `__init__.py` as single sources of truth. All 20 files that reference the old .tox name, version strings, or inline transport normalization get updated. CI gains a bundle integrity check. The .tox binary is exported from connected TouchDesigner as the final step.

**Tech Stack:** Python 3.10+, FastMCP, TouchDesigner MCP tools

### Task 17: Add CI bundle integrity check

**Files:**
- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1: Add integrity step**

After the last step in the CI workflow, add a new step:

```yaml
      - name: Validate bundle integrity
        run: |
          uv run python -c "
          import json, sys
          from td_mcp import __version__, TOX_FILENAME
          manifest = json.load(open('mcp/manifest.json'))
          errors = []
          if manifest['version'] != __version__:
              errors.append(f'manifest version {manifest[\"version\"]} != {__version__}')
          expected_tox = f'td_component/{TOX_FILENAME}'
          if manifest['artifacts']['td_component_tox'] != expected_tox:
              errors.append(f'manifest tox {manifest[\"artifacts\"][\"td_component_tox\"]} != {expected_tox}')
          if errors:
              print('\n'.join(errors)); sys.exit(1)
          print('Bundle integrity OK')
          "
```
