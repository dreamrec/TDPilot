# v1.3.0 Knowledge Foundation — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.3.0 with `standard` safety mode, expanded capabilities, resource read-through fallbacks, knowledge corpus infrastructure, and 8 new knowledge tools (63 to 71).

**Architecture:** Add a `knowledge/` package under `src/td_mcp/` with JSON card index, optional web fetcher, and provenance tracking. Extend the safety system with a curated-import `standard` tier on both MCP server and TD sides. Expand `CapabilitySet` to 10 fields. Add read-through fallbacks to cached resources. Register 8 new tool handlers in `tool_registry.py`.

**Tech Stack:** Python 3.11+, FastMCP decorators, MCP SDK 1.26.x, JSON card corpus, optional `httpx` for web fetch.
