# v1.3.2 TD 2025 Native — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 11 new tools (76-86) covering vision diagnostics, TD 2025 native system inspection, official-component recommendation, and memory/technique upgrades with compatibility and validation.

**Architecture:** New tools split into three categories: (a) vision tools that add a TD-side `/api/analyze_frame` endpoint using numpy for pixel analysis, (b) system inspection tools that query TD 2025 subsystems via `standard` exec or dedicated endpoints, and (c) knowledge-only tools that query the CardIndex corpus. Memory upgrades enhance the existing analyzer and technique store with build compatibility, layout capture, and pre/post-replay validation — no new tools, just richer data.

**Tech Stack:** Python 3.11.10 (TD 2025.32460), numpy (shipped with TD), FastMCP, Pydantic input models, JSON knowledge cards.

  ```python
  def update_validation(self, technique_id: str, validation: Dict[str, Any], scope: str = "project") -> bool:
      store = self._store_for(scope)
      entry = store.get(technique_id)
      if not entry:
          return False
      entry["validation_result"] = validation
      # Auto-promote state based on validation
      if validation.get("status") == "pass" and entry.get("state") == "candidate":
          entry["state"] = "validated_local"
      elif validation.get("status") == "fail":
          entry["state"] = "deprecated" if entry.get("state") in ("validated_local", "validated_portable") else entry.get("state", "candidate")
      entry["updated_at"] = datetime.now(timezone.utc).isoformat()
      self._save_scope(scope)
      return True
  ```
